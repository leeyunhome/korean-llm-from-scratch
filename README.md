# 한국어 LLM, 바닥부터 (korean-llm-from-scratch)

한국어 언어 모델을 바닥부터 직접 만들어 보며 얻은 결과를 시각화해 모은 포트폴리오입니다.

**사이트: https://leeyunhome.github.io/korean-llm-from-scratch/**

사이트는 `docs/` 폴더의 Markdown으로 만들며, GitHub Pages([Just the Docs](https://just-the-docs.com) 테마)로 게시합니다.

[홍랩(HongLab)](https://www.honglab.ai) 강의에서 배운 내용을 토대로 직접 구현·분석한 개인 학습 기록입니다. 강의 영상·자료·강의에서 제공한 데이터와 강의의 구현 방법은 포함하지 않습니다.
